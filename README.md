1.Разница: Результат одинаковый. Но `+=` вычисляет переменную один раз и делает неявное приведение типов (например, `byte += int` сработает, а `byte = byte + int` — нет).

2.Разница: `x++` возвращает старое значение, а потом увеличивает. `++x` сначала увеличивает, а потом возвращает новое.

3.Тип: Всегда `bool` (`true` или `false`).

4.Короткое замыкание: Если результат ясен по левому операнду, правый не вычисляется. 
*Пример*: `if (user != null && user.Name == "Admin")` — если `user` равен `null`, вторая часть не выполнится, и программа не упадёт.

5.Приоритет: `10 - (2 * 3) + (4 / 2) = 10 - 6 + 2 = 6`. (Умножение/деление выше, затем слева направо).

6.Скобки: Для читаемости. Читающему не нужно держать в голове приоритеты операторов, скобки сразу показывают логику и предотвращают ошибки.
